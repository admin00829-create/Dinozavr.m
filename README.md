# 🌋 Vulqon Yugurish

Dinozavrlar davrida o'tadigan brauzer uchun cheksiz yugurish o'yini (Chrome "dino" o'yiniga o'xshash). Bitta `index.html` fayl, hech qanday kutubxona yoki build kerak emas.

## O'ynash

- **Sakrash:** `Bo'sh joy`, `↑` yoki `W`, yoki ekranga tegish
- **Egilish:** `↓` yoki `S` (ushlab turing). Havoda bosilsa, tezroq tushadi
- **Pauza:** `P` yoki `Esc`
- Telefonda ekrandagi tugmalardan foydalaning

## Xususiyatlar

- Davrlar: Trias → Yura → Bo'r → Muzlik (ball oshgani sayin)
- Kun va tun almashinuvi, vulqon, yulduzlar
- 300 balldan keyin pterodaktillar
- Rekord brauzerda (`localStorage`) saqlanadi
- Ovoz, pauza, telefon uchun moslashgan to'liq ekranli maydon

## Ishga tushirish

Mahalliy: `index.html` faylni brauzerda oching.

### GitHub Pages orqali joylash

1. Repozitoriyga `index.html` va `README.md` ni yuklang.
2. **Settings → Pages** bo'limiga kiring.
3. **Source** ni `Deploy from a branch` qiling, branch: `main`, papka: `/ (root)`.
4. Bir necha daqiqadan keyin o'yin `https://<login>.github.io/<repo-nomi>/` manzilida ochiladi.
